# Nukietris
Tetris for beginners ig?

[![Play Nukietris](https://img.shields.io/badge/%E2%96%B6%20PLAY%20NOW-Nukietris-3ecf6e?style=for-the-badge)](https://nukie63.github.io/Nukietris/)

**Version:** N63.1.5.2 · **Language:** HTML (single file, runs in the browser)

Like TETR.IO or Jstris, but with extras. Let's goooo!

## Features
- SRS rotation, hold, 180 spin, T-spins
- All-spin attacks, B2B and combo meter with pop-up numbers
- Perfect Clear: message, B2B and a 10 line attack
- TETR.IO style handling sliders in frames (DAS, ARR, SDF, DCD) and key rebinding
- Practice vs bot with 10 levels, plus a tournament bot that plays like a pro
- Fight Nukie boss with nukes, lightning and a skull curse (yeah dont ask I WAS BORED OKAY????)
- Power-ups: Gold shield, Ice stun and Purify
- Training menu: Practice with Bot, Sandbox, Finesse, Flood, 4-Wide and Fight Nukie
- Effects, particles and shake effects, with settings in Options
