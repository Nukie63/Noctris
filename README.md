## 🆕 What's new in N63.1.6.0 Beta

### ✅ New

| | |
|---|---|
| 🖌️ **Hand-drawn art** | New blocks, pop-ups for lines, spins, combo and B2B, the falling Nuke and Ice, projectiles, Nukie's faces and the logo |
